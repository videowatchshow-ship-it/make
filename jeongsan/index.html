📖 사용 설명서 (눌러서 펼치기 / 접기)
💵 이 페이지 = 회원별 테더/캐쉬 입금 정산
회원 한 명 한 명의 입금 건을 한 줄씩 기록하는 표입니다.

■ 입력 방법
① ＋ 회원 추가 버튼 → 빈 줄 생성
② 각 칸(날짜·출발·종료·닉네임·실명·입금종류·입금액·결과·롤링금·비고) 클릭해서 입력
  · 입금종류: 테더 / 캐쉬
  · 결과: Lose=손님 패(우리팀 수익) / Win=손님 승(마감, 수익 0)
  · 수익은 자동 계산: (입금액 − 롤링금) × 30%
③ 다 넣으면 💾 서버에 저장 → 팀원 전체 공유 + 자동 백업

■ 엑셀로 뽑기
이 페이지엔 엑셀 다운로드 버튼이 없습니다. 엑셀(.xlsx)이 필요하면 상단 → 엑셀 정산표 페이지에서 ⬇️ 엑셀로 내보내기를 쓰세요.

■ 페이지 이동 — 위 링크로 엑셀 정산표 · 일일정산(우동카) 이동.

회원 수익 = (입금액 − 롤링금) × 30%  ·  Lose=우리팀 수익 / Win=손님 승(마감)
→ 일일정산  ·  → 엑셀 정산표

① 회원 입금 정산표

날짜 출발시간 종료시간 닉네임 실명(예금주) 연락처 계좌번호 입금종류 입금액 $ / 누적 역송액 $ / 누적 결과 롤링금 $ 수익 / 상태 비고

② 개인 차용 장부

사람별 가로 열 · 칸에 금액만 입력하면 사람별 합계와 총합이 자동 계산돼요.
# 제이 센트 탁 데니(퇴사) 하바드

총 차용 합계 0
