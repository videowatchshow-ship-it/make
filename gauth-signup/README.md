# gauth-signup — 구글 계정 가입 프론트엔드

배포 도메인: `https://gauth.cent-solution.online/signup` (또는 별도 경로)
서버 경로: `/var/www/sites/gauth/public/signup.html`

## 파일

| 파일 | 역할 |
|------|------|
| `signup.html` | 구글 계정 신규 가입 UI |

## 배포

`.github/workflows/` — SCP로 서버 public 디렉토리에 복사
