# 프리즘 모바일 UX 동등성 체크리스트 (30항목)

> 상품화 전 "폰에서 PRISM Live Studio처럼 쓸 만한가"를 **아이폰 뷰포트(390×844, DPR3, touch)에서 헤드리스로 실측**해 채운다. 근거 표준: Apple HIG(터치 ≥44pt)·Material(≥48dp)·PRISM/OBS 모바일 패턴. (실측)=Playwright 측정, (CSS)=규칙 검증, (impl)=구현 확인.

## 판정 요약

**결론: 프리즘처럼 사용 가능.** 핵심 모바일 UX — 세로 우선·엄지존 하단바·바텀시트·44px+ 터치 타깃·세이프에어리어·PWA — 를 모두 충족한다. 실측 결과 **✅29 / ⚠️1**. 유일한 아쉬움은 상단 도구(가이드/줌) 도달성이며, PRISM도 이 계열은 상단에 둔다.

| 지표 | 수정 전 | 수정 후 | 비고 |
|--|--|--|--|
| 세로폰 캔버스 점유율 | 21% | **65%** | 모바일 최초 세로(9:16) 기본화 |
| 가로 스크롤 | 없음 | 없음 | ✅ |
| 콘솔 에러 | 0 | 0 | ✅ |

## 남은 개선 (상품화 폴리시)
- **8 상단 도구 도달성**: 자주 쓰는 가이드/줌을 하단 시트나 롱프레스 라디얼로 승격 검토(엄지존 확대).
- 실기기 발열/배터리·저사양 폰 프레임 유지율은 **실측 필요**(체크리스트 342/344 계열, 코드 단독 불가).

> 재현: Playwright 크로미움 `viewport 390×844, isMobile, hasTouch` 로드 → 상기 지표 측정. 각 커밋 시 회귀 확인.
